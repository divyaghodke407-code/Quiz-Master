# QuizMaster AI 🎯

### AI-Powered Mini Mock Test Platform

QuizMaster AI is a simple and interactive quiz application designed to help students practice questions, test their knowledge, and improve their learning experience.

The project provides a user-friendly interface for taking mini mock tests and checking quiz performance.

## ✨ Features

* Interactive quiz interface
* AI-powered quiz assistance
* Multiple-choice questions
* Instant answer feedback
* Simple and responsive user interface
* Beginner-friendly design
* Easy to use

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* Hugging Face API

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/divyaghodke407-code/Quiz-Master.git
```

### 2. Navigate to Project Folder

```bash
cd Quiz-Master
```

### 3. Install Dependencies

```bash
cd backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder.

```env
HF_API_KEY=your_huggingface_api_key
PORT=5000
```

Replace the placeholder with your actual API key.

### 5. Start the Backend Server

```bash
node server.js
```

### 6. Run the Application

Open `index.html` using Live Server in VS Code.
